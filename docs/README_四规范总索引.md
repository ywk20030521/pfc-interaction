# PFC Interaction 5.0 — 四份技术规范总索引

**用途：** 本索引定义四份强制规范的适用关系，不替代任何一份规范。

## 规范清单

1. `01_总体架构与科研工作流规范.md` — PFCI-ARCH-5.0
2. `02_科研专业模块与技术能力规范.md` — PFCI-MOD-5.0
3. `03_人机协作与决策协议规范.md` — PFCI-HUMAN-5.0
4. `04_提问卡片强制设计规范_V2.md` — PFCI-CARD-5.0

## 约束关系

- 01 是总体架构和科研工作流的上位规范。
- 02 约束 M1–M6 的专业职责和技术接口。
- 03 约束 Agent 与研究人员之间的讨论、决策、授权和反馈。
- 04 约束所有结构化提问卡片的内容、视觉和交互行为。

## Skill 必须遵守的执行规则

1. `SKILL.md` 必须引用并要求遵守四份规范。
2. 模块说明、模板、示例不得违反四份规范。
3. 同一事项发生冲突时，先检查是否属于不同责任域；不得简单复制一份规则覆盖另一份。
4. 总体架构冲突以 01 为准；模块职责以 02 为准；交互与授权以 03 为准；卡片呈现以 04 为准。
5. 规范中描述的目标能力不得自动标记为已实现。实现状态和验收证据应独立记录。
6. 修改任一规范时，必须检查其他三份文件及 `SKILL.md` 的交叉引用和一致性。

## 建议在 SKILL.md 中加入的强制引用

> 本 Skill 必须遵守以下四份规范：总体架构与科研工作流规范、科研专业模块与技术能力规范、人机协作与决策协议规范、提问卡片强制设计规范。四份规范共同构成 PFC Interaction 5.0 的强制约束。不得以简化实现、宿主限制或局部模块便利为由静默绕过；如某项能力受环境限制，必须明确报告限制和降级行为。
