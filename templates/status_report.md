# 模板：实验状态汇报

用于阶段汇报、任务进度、关键节点。所有数值必须来自真实工具返回。

---

**[阶段汇报] <实验名> · <当前阶段>**

**观测事实**
- 当前阶段：<如 压密 / 加载 / 峰后>；任务状态：<running/completed/interrupted>；循环步：<N>
- 关键指标：<名称> = <数值> <单位>（来源：<工具名>，阶段：<阶段>）
- 变化：<与上一点/上一阶段比较>

**趋势判断**（如适用）
- <基于多个观测点的判断，注明比较区间>

**机理解释**（如适用，标注不确定性）
- <可能的物理解释；"可能/推测"等措辞不可省略>

**当前状态结论**
- <一句话：是否符合预期、是否到达决策节点>

**下一步建议**（如适用）
- 方案 A：<动作 + 预期收益 + 风险>
- 方案 B：<动作 + 预期收益 + 风险>

**待确认事项**（仅在需要用户参与时）
- <需要操作者决定的具体问题，含选项与推荐>

---

使用说明：
- 无趋势/解释/建议时删除对应段落，不填占位文字；
- 数值缺失时写"未能获取（<原因>）"，不填假设值；
- Console 无头模式不得声称已生成 plot 图件。
